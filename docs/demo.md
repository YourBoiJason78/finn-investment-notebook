# FINN demo — about three minutes

Start with Research → INFY. These are historical FY2025 figures, not the latest results.

**0:00 — The point.** “I wanted to build something that helps me check a claim, not just read another summary. The same result can look good or bad depending on which promise you compare it with.”

**0:20 — The comparison.** Show 1–3% original guidance and 4.2% actual growth. Switch to Revised: 4.5–5% guidance, the same 4.2% outcome. Open the evidence and point to the dated transcript. Switch to Margin and show the comparable 20–22% band and 21.1% result.

**0:55 — The boundary.** Open TCS. Explain why a broad AI capability ambition does not get a numeric pass/fail badge. “I would rather show what I could verify and leave a question open than create a confident score from incompatible metrics.”

**1:15 — Fresh research.** Enter WIPRO. Show document links, page numbers and partial-reading warnings. Ask about revenue growth. If no model is configured, call this retrieved evidence, not an AI-generated answer. Network extraction can take a minute; use a previously opened company if time is tight.

**1:50 — The daily workflow.** Open The brief and choose Last 30 days. Show one material filing and the folded routine list. Explain the ranking is rule-based. Open Preferences for the price/volume thresholds. Point out collection and price observation dates.

**2:20 — Remember the question.** Save “Will operating margin remain within guidance?” Open Watching, then reload to demonstrate persistence. “A newer filing invites review; it doesn't automatically settle my question.”

**2:45 — Tradeoffs.** Briefly explain bounded PDF reading, on-demand checks and browser-local storage. Close with the next improvement: broader retrieval and claim-level verification, followed by scheduled notifications.

## Before recording or sharing

- Open the exact hosted URL and make sure the intended reviewer can access it. Owner-private access is not sufficient for submission.
- Confirm the displayed dates and refresh status; never describe the snapshot as live streaming data.
- If showing AI synthesis, configure a model and test the actual answer and each citation first.
- Remove demo questions you do not want to keep. Do not clear unrelated browser data.
- Review the code and explanations in your own words; the repository openly records AI assistance.
- Supply the real conversation export or share link separately. `ai-history.md` is a summary, not a transcript.
